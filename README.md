# CBTA DG Assessment (CAR Part VI Table 4.1.D)

30-minute CBTA simulation for dangerous goods acceptance staff at air freight forwarders.
Student views: `/#student` (Table 4.1.D) and `/4e#student` (Table 4.1.E). Trainer view: `/#trainer` with a switch to `/4e#trainer` (trainer PIN set in the `TRAINER_PIN` variable).
Results are stored on the Railway volume (`DATA_DIR`): results.json (4.1.D) and results-4e.json (4.1.E). Pages are built with project files simulations/build/build_site.py.
